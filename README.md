# Stereo Space! 🎧

A Minecraft mod that brings true positional stereo audio to the game. Stereo sounds are split into two mono channels that always face the player, so music and other stereo audio feel like they exist in the world around you.

## Details

Made for Minecraft 1.21.1 and available for both Fabric and NeoForge.

## Building

Run the following command in the project root:

```
gradlew build
```

The built jars can be found in the `fabric/build/libs` and `neoforge/build/libs` folders.
